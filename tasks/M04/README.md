# Milestone M04 – Hero Section

## Overview

Milestone 4 implements the Hero section of the homepage, which creates the premium first impression for visitors. The Hero section immediately communicates Ankit's professional identity, includes primary and secondary CTAs, uses NeoPOP-inspired visual composition, and ensures responsive behavior with animations.

## Execution Order

The tasks should be implemented in the following order:

1. M04.01 – Hero typography and basic layout
2. M04.02 – Primary CTA buttons (Explore My Work, Ask My AI)
3. M04.03 – Secondary CTA buttons (Download Resume, LinkedIn, GitHub)
4. M04.04 – NeoPOP visual composition (layered cards, elevated elements)
5. M04.05 – Animations using Framer Motion (floating tokens, subtle movements)
6. M04.06 – Responsive behavior and reduced-motion support
7. M04.07 – Integration into app/page.tsx and final polishing

Tasks M04.01 through M04.03 can be worked on in parallel after the basic layout is established. M04.04 and M04.05 depend on the basic layout. M04.06 depends on the visual composition. M04.07 is the final integration.
