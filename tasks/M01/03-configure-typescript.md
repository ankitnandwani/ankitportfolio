# M01.03 — Configure TypeScript

## Objective

Enable strict TypeScript checking and fine‑tune the compiler options for the Next.js project.

## Context

The roadmap’s Architecture milestone calls for “Configure TypeScript, linting, formatting, environment validation.” This task isolates the TypeScript configuration so it can be verified independently. The PRD’s technical architecture (Section 52) expects a strongly typed codebase.

## Requirements

- Edit `tsconfig.json` to enforce the following settings (in addition to the defaults generated by `create-next-app`):
  ```json
  {
    "compilerOptions": {
      "strict": true,
      "noImplicitAny": true,
      "noImplicitReturns": true,
      "noFallthroughCasesInSwitch": true,
      "forceConsistentCasingInFileNames": true,
      "resolveJsonModule": true,
      "skipLibCheck": true,
      "incremental": true,
      "baseUrl": "./",
      "paths": {
        "@/*": ["src/*"]
      }
    }
  }
  ```
- Ensure `include` contains `next-env.d.ts`, `src/**/*.ts`, `src/**/*.tsx`, and any other source directories.
- Add a script `typecheck` to `package.json` that runs `tsc --noEmit`.
- Commit the updated `tsconfig.json` and `package.json` changes.

## Scope

### In scope
- Modifying `tsconfig.json`.
- Adding the `typecheck` script.

### Out of scope
- Changing any application logic.
- Adding third‑party TypeScript libraries.

## Dependencies

- **M01.02** – The Next.js scaffold must exist before the TypeScript file can be edited.

## Files / Areas Expected To Change

- `tsconfig.json`
- `package.json`

## Implementation Guidance

- Preserve the existing Next.js compiler options (e.g., `jsx`, `moduleResolution`).
- Use the `paths` alias `@/*` to simplify imports; this aligns with the folder structure we will create later.
- Run `npm run typecheck` locally to verify that the configuration produces no errors on the scaffolded code.

## Acceptance Criteria

- [ ] `tsconfig.json` includes all required strict options.
- [ ] `npm run typecheck` completes with a zero‑exit code on the scaffolded project.
- [ ] The `typecheck` script is present in `package.json`.
- [ ] The changes are committed.

## Testing Requirements

Execute `npm run typecheck` and confirm that the output reports **0 errors**.
